# CTSEG Global Sourcing Implementation Plan

**Goal:** credible worldwide B2B sourcing with preserved locale and lead infrastructure.
**Architecture:** shared multilingual editorial template, static industry/capability routes, existing contact delivery, audited retirement map.
**Tech Stack:** Astro 7.4.7, TypeScript, CSS, Cloudflare Pages, existing Playwright tooling.
**Spec:** design.md plus user-supplied three briefs.

## Constraints
No fictional partnerships, marketplace inventory, legal registrations, offices or guarantees. No dependency upgrades. All 13 languages and RTL retained. Food secondary, glass retired. No production deployment or own merge.
